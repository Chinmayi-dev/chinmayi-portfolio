# Chinmayi D — Portfolio

A personal portfolio showcasing my work in software development, AI/ML, data science, backend systems, and full-stack applications.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Icons

## Highlights

- Animated portfolio intro
- Responsive single-page design
- Technical skills showcase
- Internship and project experience
- Project cards with detailed views
- Education and certifications
- Contact and social links

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
``` 

## Project Content

Most portfolio content is managed in:

```bash
src/data/portfolio.js
```
